HTML edition: what works and its limitations

  • Works offline in any modern browser: CSV upload, validation, calculations, threshold changes, ratio cards, monthly sales chart, three review stages, carry-forward and CSV export.
  • Storage: findings and notes are saved in this browser's localStorage for this file location. They are lost if browser data is cleared, are not shared with other browsers or people, and private/incognito windows may not keep them. Use Export workspace regularly and Import workspace to restore.
  • No direct AI calls: a web page cannot keep an API key secret, so this file never asks for or embeds one. Use Copy AI prompt to copy a prompt containing only the verified figures for use in an approved AI assistant, then paste the reply into the draft box. It stays labelled "Draft—Subject to Auditor Review". The Python desktop app can call the AI directly, with the key stored outside the source code.
  • Single user: there is no audit trail of who made changes beyond the history log in each finding.
  • Calculations mirror the Python app: same sign conventions, checks, ratios and threshold rules.

This tool highlights movements for auditor follow-up. It does not give an audit opinion and does not reach conclusions about fraud or misstatement.
