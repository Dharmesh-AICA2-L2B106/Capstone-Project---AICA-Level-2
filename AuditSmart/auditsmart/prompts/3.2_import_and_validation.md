```
Implement importer and validation services with async endpoints per SPEC 3.3:
chunked upload to storage; SHA-256; parse to Parquet in chunks; header-synonym
mapping with override; dd/mm/yyyy, ISO and Excel serial dates; amounts with commas,
brackets, trailing minus. Checks: Dr = Cr per voucher and in total (tolerance from
rules), missing mandatory fields, bad dates, duplicate line_ids, voucher gaps,
optional GL vs TB per account. Each error: severity (critical/warning), row numbers
(first 50 + count), field, message in plain English with guidance, e.g. "Voucher
JV-0142 is out of balance by AED 0.05 (rows 142, 387). Correct the source file or
exclude the voucher with a reason." Block downstream endpoints while critical errors
exist. Tests using edge_cases.csv must produce each expected error.
```
