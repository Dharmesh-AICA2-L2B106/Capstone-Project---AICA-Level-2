# 3.7 Anonymiser and AI gateway — plan

Prompt: prompts/3.7_anonymiser_and_ai_gateway.md. AI drafts wording only; it never calculates. Decisions D21–D23.

1. `services/anonymiser.py`
   - `build_payload(...)` emits only the whitelisted keys: area, test, item_ref, amounts, failed_attribute, applicable_references, auditor_remark.
   - `scrub(text, names)` replaces known names (client name/code, party names, user ids, supplier register names) and patterns: e-mails, IBANs, Emirates ID (784-…), 15-digit TRNs, UAE phones, company-suffix names (LLC, FZE, FZCO, PJSC, Est.), honorific + name.
   - `assert_clean(payload, forbidden)` re-serialises the payload and raises if any forbidden term or pattern is still present (defence in depth; the AI call never runs if it fails).
   - `forbidden_terms(engagement, dataset)` gathers the deny list from the DB, the dataset parquet and data/supplier_register-style register rows.
2. `services/ai_gateway.py`
   - The system prompt is copied into engine/app/ai_prompts/observation_v1.txt (a test asserts it equals prompts/observation_system_prompt.txt). PROMPT_VERSION = `observation@v1+<sha8>`.
   - Provider adapters: `GeminiProvider`, `AzureOpenAIProvider` (urllib; transport injectable; keys read from env at call time and never logged or stored) and `StubProvider` (offline, deterministic). Chosen by `AI_PROVIDER` (`gemini` | `azure_openai` | `stub`; empty → 503 "AI not configured").
   - Temperature 0.2. JSON parsed (code fences stripped), validated by Pydantic `ObservationDraft` (7 fields, extra=forbid). One retry with a corrective message. Second failure → 502.
   - Draft label appended to `wp_conclusion` if missing. Word count > 220 → warning.
   - Result stores provider, model, prompt_version, attempts.
3. API
   - `POST /v1/ai/observation` {sample_item_id, failed_attribute, test, remark, rule_keys} → 201: the observation is stored with ai_generated=True, prompt_version and model; the response includes the anonymised payload sent.
   - `GET /v1/observations/{id}`.
   - `POST /v1/observations/{id}/review` (Senior/Manager/Partner; optional edited text) sets reviewed_by/reviewed_at, which unlocks the WP gate (3.6).
   - Audit log stores ids, prompt version and model only (no payload).
4. Tests: all providers are mocked. A socket guard proves there is no network. The security test fails if any party name, client name or TRN from data/*.csv appears in any payload. Retry/502, label, adapters' request shapes (fake transport), 503 when unconfigured, review flow → WP.
