## Design decisions
- **Money:** Decimal only; no float in services.
- **Authentication:**
  - AUTH_PROVIDER is `entra` | `supabase` | `dev`.
  - Issuer and audience are always checked; exp/nbf are required.
  - **Roles:**
    - Entra: the `roles` claim.
    - Supabase: `app_metadata.roles` or `app_metadata.role`.
    - Mapped to Admin, Partner, Manager, Senior, Staff, TaxPartner.
  - **Dev mode:** works only when ENVIRONMENT=development, signed with a local secret, for Savio's local testing.
- **Dependencies:**
  - `require_roles(*roles)`.
  - `require_engagement_member(engagement_id, roles=...)`, which checks the engagement_members table.
- **Health:**
  - Public; returns `{status, service, version, environment, db, queue}`.
  - queue = "in-process" when REDIS_URL is empty; otherwise the result of a Redis ping.

## Tests (pytest)
- Health returns the version and reports db ok and queue in-process.
- Config defaults and the env override.
- **JWT:**
  - valid Entra token
  - valid Supabase token
  - wrong issuer, wrong audience, expired token, bad signature, `alg=none` → 401
  - missing token → 401
- Role dependency → 403.
- Membership dependency: member allowed, non-member gets 403.
- CORS: an allowed origin gets the header; a foreign origin does not.
- Logging: non-whitelisted fields are dropped, and TRN/email patterns are scrubbed.
- Alembic `upgrade head` on a temporary SQLite database creates every Appendix A table.

## Commands
```
uv pip compile requirements.in -o requirements.txt --python-version 3.11
uv pip install -r requirements.txt -r requirements-dev.txt
ruff check . && mypy && pytest --cov
uvicorn app.main:app   # check that /docs and /v1/health respond
```

## Not in scope / deviations
- Docker image build: Docker is not installed on the box, so the Dockerfile is written but not built.
- PostgreSQL/Redis are not installed (the Workbook caution allows this); the code stays Postgres-ready (psycopg in the requirements).
- Pre-commit hooks are configured, but `pre-commit install` needs a git hook in Savio's own clone.
