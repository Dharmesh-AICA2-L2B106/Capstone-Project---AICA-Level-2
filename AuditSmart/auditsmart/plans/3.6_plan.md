# 3.6 Working paper (ISA 230) — plan

Prompt: prompts/3.6_working_paper_isa_230.md. Defaults per firm_methodology_v0.2; decisions D18–D20.

1. `services/workpaper.py`
   - `collect(engagement_id, sample_id?, je_run_id?, input_vat_run_id?, overrides)` loads stored results (no recalculation) and applies the gate:
     - any included result with status STALE → refuse (409) unless the request carries a justified override from a Manager/Partner (D19);
     - any AI-generated observation on the included sample without `reviewed_by` → refuse (409).
   - `build_workbook(data) -> bytes` (openpyxl, pure, deterministic apart from the generation timestamp) with 11 sheets, in the prompt's order: Lead, Population, Sampling, Sample & Testing, JE Risk, Benford, Evaluation, Input VAT, AI Drafts, Rules & Calendar, Sign-offs (D18: the prompt lists 11; SPEC table says "9-sheet").
   - Formatting: title block, styled header row, AED number format, column widths, frozen panes under the header, landscape fit-to-width, print titles, footer "WP ref | Page &P of &N | tool version".
   - Sample & Testing: Yes/No/N/A data-validation lists (Exists, Agreed to evidence, Correctly recorded), audited value, misstatement, evidence ref.
   - Benford: native bar chart (actual vs expected %).
   - Input VAT: filled from the input-VAT run once 3.12 stores results; otherwise "Not included".
   - Rules & Calendar: every rule version from every included result with value, status, source reference and source URL (blank until 3.8 records URLs; no URL invented); calendar hash, period, emirate and layers.
2. Persistence: `workpapers` gains `file_ref`, `sha256`, `manifest` JSON, `created_at` (migration 0004, `# +`); the file is stored under storage/workpapers/. Audit log row per generation.
3. API: `POST /v1/workpaper` → 201; `GET /v1/workpapers/{id}` metadata; `GET /v1/workpapers/{id}/file` download.
4. Tests: unit (builder: every sheet, key cells, validations, chart, freeze panes, footer, print setup), gate (stale, override, unreviewed AI draft), API (201, download, 404/403/409/422).
