## Design
1. **app/services/calendar.py (core, brought forward from 3.10)**
   - Pure layer model: federal week/holidays < emirate week/holidays < company work week < company exception.
   - resolve(profile, start, end) -> DayStatus(is_working, reason, half_day_cutoff, source, provisional). There is no hard-coded weekend: a missing work week raises CalendarError.
   - The DB loader resolve_engagement() falls back to seed_data/calendar_seed.json for the federal layer.
   - calendar_hash = sha256 of the canonical resolved days.
   - 3.10 adds the API, Excel import/export, overlap validation, Asia/Dubai conversion and STALE marking.
2. **app/services/je_tests.py**
   - Per-line criteria, with parameters from rules (je.*) that the request can override:
     - non_working_day (reason weekend / holiday / company_closure)
     - after_half_day_cutoff
     - round_sum (multiple of 1,000 and >= 10,000)
     - period_end (±5 days)
     - rare_user (< 1% of entries)
     - senior_user (configured list)
     - large_amount (>= PM, when supplied)
     - vague_narration (keyword list)
     - manual_sensitive (manual voucher prefix to revenue/cash)
     - duplicate_invoice (same party + invoice, later voucher)
     - duplicate_party_amount_date
     - unusual_account_pair (< 3 vouchers)
     - unbalanced_voucher
   - risk_score = number of criteria met. Selection: score >= 3 "test", score 2 "judgement". Never random.
   - Output: summary per test (lines / vouchers / value), flags per line, calendar_hash, rule versions and engine version.
   - Runs as a jobs.submit background job. Persisted in JeRun (+ result JSON, created_by, created_at, job_id) and JeFlag. Migration 0003 also adds emirate_profiles.half_days.
3. **app/services/benford.py**
   - First digit of |amount| >= 10.
   - Chi-square via scipy.stats.chi2 (df 8); the alpha comes from rules.
   - MAD thresholds from rules: 0.006 / 0.012 / 0.015 (Nigrini first digit).
   - Returns the conclusion and chart data.
4. **API**
   - POST /v1/je-tests -> 202 {job_id, je_run_id}.
   - GET /v1/je-tests/{id} -> result.
   - POST /v1/benford -> 200.
5. **Tests**
   - Calendar unit tests.
   - JE unit tests.
   - Benford unit tests (a uniform-log sample conforms; a planted spike gives nonconformity).
   - Detection golden test: prints planted vs detected per answer-key type for dummy_gl and fy2021_2022, and must be 100%.
   - API tests.
