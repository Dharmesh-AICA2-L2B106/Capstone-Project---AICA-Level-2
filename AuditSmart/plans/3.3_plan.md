## Algorithm
1. **Population.** Filter by `account_types` / `account_codes` (supports a `prefix*` wildcard) and take the value by basis:
   - debit (default): credit lines are listed as excluded
   - credit
   - signed: negatives are listed as excluded
   - absolute
   - Zero lines are counted and excluded.
2. **Size (firm).**
   - Exp = pct × TM; refused if pct > 50% or pct < 0.
   - n = ceil(Pop × CF / (TM − Exp × EF)); if Exp = 0 there is no EF.
   - Guide option: n = ceil(Pop × CF / TM).
   - J = Pop / n (full Decimal precision); BP = CF × J.
3. **Below the minimum.** n < `sampling.min_n` gives status `no_sampling` with a plain message, and nothing is selected.
4. **Start.** `numpy.random.default_rng(seed).random()` → Decimal → × J, truncated to 0.01.
   - The seed is a random 31-bit value when not given, and it is always returned.
5. **Selection.** For k = 0..n−1, point = start + kJ; take the first line whose cumulative value ≥ point. This is identical to golden `COUNTIF(cum,"<"&point)+1`.
   - Lines are distinct, with hits counted; top stratum = value ≥ J.
   - A warning is given if the distinct count is more than 10% below n.
6. **Random.** Without replacement (rng.choice).
7. **Systematic.** Count interval N/n with a random start; index = floor(start + k·step).
8. **Stratified.**
   - Strata come from user upper bounds, or from equal-count quantile strata (default 3).
   - Allocation is proportional to value, with a minimum of 1 and a cap at the stratum size (largest remainder); random selection within each stratum.
9. **Key items + MUS.** Lines ≥ threshold are tested 100%; MUS is run on the remainder.
