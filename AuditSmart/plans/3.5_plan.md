## VAT service (`app/services/vat.py`)
- **Scope:** every line with a VAT code. Side = output for Revenue accounts, input for all others.
- **Rules:** for each line, the rule version valid on the invoice date (entry_date, else posting_date):
  - `vat.rate.<CODE>`: SR 0.05, ZR 0, EX 0, RC 0.05 (pending_verification)
  - `vat.tolerance`: 0.01, the golden placeholder
  - `validation.trn_pattern`
- **Calculation:** expected = ROUND_HALF_UP(net × rate, 2); difference = recorded − expected; exception when |difference| > tolerance.
- **Exception types:**
  - unknown code (no rule)
  - missing net amount
- **Likely cause** (descriptive only, never used to decide an exception):
  - VAT not charged
  - VAT on the gross amount
  - a different rate
  - other difference
- **TRN check:** non-blank TRNs that fail the pattern, with the reason (length, prefix or non-digit).
- **Output:**
  - a summary by side and code: lines, net, recorded, expected, difference, exceptions
  - rule_versions_used and the pending-verification flag
- **API:** `POST /v1/vat-check {dataset_id, sides?}` returns 200. A 409 guard applies. The run is synchronous and deterministic, so it is not stored; the workpaper (3.6) re-runs it.

## Evaluation service (`app/services/evaluation.py`)
- **MUS (D2 default)**, reproducing the golden "Projection" sheet:
  - Items ≥ J (top stratum) and key items: actual misstatement.
  - Items < J: tainting = m / book; projected = tainting × J.
  - Overstatements below J are ranked by projected value, descending. Ties share a rank, as in the golden COUNTIFS. IA = Σ projected × (factor − 1), with factors from `sampling.mus.if.<level>`.
  - Ranks beyond the table use the last factor and record a warning (D14).
  - BP = CF × J; UML = BP + Σ projected + IA; the conclusion compares UML ≤ TM ("Acceptable" or "Exceeds - further work").
  - Understatements are projected the same way but reported separately (D15). They do not reduce the overstatement UML.
  - 80% / 99% with errors below J: refused (D6).
- **Ratio projection (non-MUS, or `method: "ratio"`):**
  - Projected = Σ m / Σ book × the population value of the sampled part, worked per stratum for stratified samples. Key and top-stratum items are added at their actual value.
  - The conclusion compares the projection with TM. A note says no allowance for sampling risk is computed (D16).
- **API:** `POST /v1/evaluate {sample_id, method?, tolerable_misstatement?, items:[{line_ref, audited_value, remarks?, evidence_ref?}]}`.
  - Items not listed are treated as audited = book.
  - An unknown line_ref gives 422.
  - Audited values and misstatements are stored on SampleItems; the evaluation is stored in `samples.result.evaluation`.
  - `GET /v1/samples/{id}` returns it.
